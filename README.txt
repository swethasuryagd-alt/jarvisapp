JARVIS (wake word + typing + Groq)

BUILD: open this folder in Android Studio and run Build > Build APK,
or push it to GitHub: the included workflow builds app-debug.apk.

KEYS (free):
- Groq key:        console.groq.com
- Picovoice key:   console.picovoice.ai (built-in "Jarvis" wake word)

FIRST RUN:
1. Install the APK, open Jarvis, paste both keys, tap Start, allow mic + notifications.
2. Tap Accessibility and turn on Jarvis (needed for scrolling).
3. Tap Overlay and allow (lets Jarvis open apps from the background).
4. Phone Settings > Battery > Jarvis > Unrestricted, allow auto-start, lock in recent apps.

COMMANDS (instant, no AI): "open <app>", "scroll", "scroll instagram every 5 seconds",
"stop", "turn off". Anything else goes to Groq.
